ScholarMatch: Auto-Reviewing Scholarship Applications with Strands Decider 2B and Amazon Bedrock

Description (max 512 characters):
ScholarMatch is a university scholarship reviewer that reads a student's free-text application reason and asks Strands Decider 2B whether it matches the Need-Based Financial Aid Scholarship policy. The decider returns eligible, needs_review, or ineligible with calibrated confidence. Low-confidence and vague cases are escalated to a human reviewer automatically. Deployed on Amazon Bedrock AgentCore Runtime with Amazon Nova Pro.
